# Plan 01-01: Monorepo Scaffold + Docker Compose

## Objective

Create the complete monorepo directory structure, Docker Compose stack with all 6 services, Dockerfiles for backend and frontend, `.env.example` with all required env vars, and `.gitignore`.

## must_haves

- `docker-compose.yml` exists at the repo root and defines exactly 6 services: `api`, `frontend`, `db`, `redis`, `qdrant`, `worker`
- All services are on a shared Docker network named `edgeone-net`
- `db`, `redis`, and `qdrant` services have `healthcheck` blocks
- `api` and `worker` services declare `depends_on` with condition `service_healthy` for `db` and `redis`
- `.env.example` contains all 11 env var keys listed below (values empty)
- `.gitignore` excludes `.env`, `__pycache__`, `.next`, `node_modules`, `*.pyc`, and `.venv`
- `backend/Dockerfile` and `frontend/Dockerfile` exist and build without errors
- No secret values appear in any committed file

  Write `backend/Dockerfile` with the following exact content:

  ```dockerfile
  FROM python:3.11-slim

  WORKDIR /app

  # Install system deps
  RUN apt-get update && apt-get install -y --no-install-recommends \
      build-essential \
      libpq-dev \
      && rm -rf /var/lib/apt/lists/*

  COPY requirements.txt .
  RUN pip install --no-cache-dir -r requirements.txt

  COPY . .

  # Default CMD: run FastAPI with uvicorn
  # Override to "rq worker" for the worker service in docker-compose.yml
  CMD ["uvicorn", "api.main:app", "--host", "0.0.0.0", "--port", "8000", "--reload"]
  ```

  Note: `requirements.txt` will be created in plan 01-03. This Dockerfile will build once requirements.txt exists.

<task type="auto">
  <name>Write docker-compose.yml</name>
  <read_first>
    - .planning/1-CONTEXT.md (Docker Compose Services table: all 6 services, ports, images)
    - .planning/1-CONTEXT.md (Environment Variables section: all env var names)
  </read_first>
  <action>
  Write `docker-compose.yml` at the repo root with the following exact content:

  ```yaml
  version: "3.9"

  services:
    db:
      image: postgres:15
      restart: unless-stopped
      environment:
        POSTGRES_USER: postgres
        POSTGRES_PASSWORD: postgres
        POSTGRES_DB: edgeone_qa
      ports:
        - "5432:5432"
      volumes:
        - postgres_data:/var/lib/postgresql/data
      healthcheck:
        test: ["CMD-SHELL", "pg_isready -U postgres"]
        interval: 5s
        timeout: 5s
        retries: 10
      networks:
        - edgeone-net

    redis:
      image: redis:7-alpine
      restart: unless-stopped
      ports:
        - "6379:6379"
      healthcheck:
        test: ["CMD", "redis-cli", "ping"]
        interval: 5s
        timeout: 5s
        retries: 10
      networks:
        - edgeone-net

    qdrant:
      image: qdrant/qdrant
      restart: unless-stopped
      ports:
        - "6333:6333"
        - "6334:6334"
      volumes:
        - qdrant_data:/qdrant/storage
      healthcheck:
        test: ["CMD-SHELL", "curl -sf http://localhost:6333/healthz || exit 1"]
        interval: 10s
        timeout: 5s
        retries: 10
      networks:
        - edgeone-net

    api:
      build:
        context: ./backend
        dockerfile: Dockerfile
      restart: unless-stopped
      ports:
        - "8000:8000"
      env_file:
        - .env
      environment:
        DATABASE_URL: postgresql+asyncpg://postgres:postgres@db:5432/edgeone_qa
        REDIS_URL: redis://redis:6379/0
        QDRANT_URL: http://qdrant:6333
      depends_on:
        db:
          condition: service_healthy
        redis:
          condition: service_healthy
        qdrant:
          condition: service_started
      volumes:
        - ./backend:/app
      networks:
        - edgeone-net

    worker:
      build:
        context: ./backend
        dockerfile: Dockerfile
      restart: unless-stopped
      command: ["rq", "worker", "--url", "redis://redis:6379/0", "default"]
      env_file:
        - .env
      environment:
        DATABASE_URL: postgresql+asyncpg://postgres:postgres@db:5432/edgeone_qa
        REDIS_URL: redis://redis:6379/0
        QDRANT_URL: http://qdrant:6333
      depends_on:
        db:
          condition: service_healthy
        redis:
          condition: service_healthy
      volumes:
        - ./backend:/app
      networks:
        - edgeone-net

    frontend:
      build:
        context: ./frontend
        dockerfile: Dockerfile
      restart: unless-stopped
      ports:
        - "3000:3000"
      env_file:
        - .env
      environment:
        NEXT_PUBLIC_API_URL: http://localhost:8000
      depends_on:
        - api
      volumes:
        - ./frontend:/app
        - /app/node_modules
      networks:
        - edgeone-net

  volumes:
    postgres_data:
    qdrant_data:

  networks:
    edgeone-net:
      driver: bridge
  ```
  </action>
  <acceptance_criteria>
  - `grep "qdrant/qdrant" docker-compose.yml` returns a match
  - `grep "postgres:15" docker-compose.yml` returns a match
  - `grep "redis:7-alpine" docker-compose.yml` returns a match

  - `grep "edgeone-net" docker-compose.yml | wc -l` returns 6 (one per service)

  - `grep "6333" docker-compose.yml` confirms Qdrant port

  </acceptance_criteria>
